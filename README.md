# Bot de Trading para Binance

Bot automatizado de trading que opera en Binance usando estrategia de cruce de medias móviles.

## Características
- ✅ Conecta con Binance Testnet (sin riesgo)
- ✅ Estrategia de medias móviles (SMA 10/30)
- ✅ Operaciones automáticas de compra/venta
- ✅ Logs en tiempo real
